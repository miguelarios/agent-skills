# ---- gogcli (Google CLI) ----
# https://github.com/openclaw/gogcli
# Replaces the googleworkspace/cli (gws) skills, which were removed.
#
# Requires the `gog` binary:
#   brew install openclaw/tap/gogcli
#
# Auth model: gogcli uses your own Google Cloud OAuth client (Desktop app type),
# registered once with `gog auth credentials set <client_secret.json>`. Accounts
# are then added with `gog auth add <email> --services ...` and addressed by
# email or by alias (`gog auth alias set <alias> <email>`, then `-a <alias>`).
#
# Services authorized for this install:
#   gmail, calendar, drive, docs, slides, contacts, sheets
# Skills covering services outside that list (admin, analytics, appscript, chat,
# classroom, forms, groups, keep, maps, meet, photos, searchconsole, sites,
# tasks, youtube) are intentionally omitted. They would fail at call time
# without the matching OAuth scope. Add the scope first, then the skill.
#
# Note: openclaw skills require --dangerously-accept-openclaw-risks; the
# install script adds the flag automatically for openclaw URLs.

#
# Requires the `qmd` binary:
#   npm install -g @tobilu/qmd
#
# Heads-up on versions: this URL installs the repo's SKILL.md, which is pinned
# at skill version 2.2.0 and lags the CLI. The installed qmd CLI ships its own
# version-matched instructions -- run `qmd skill show` (or `qmd skills get qmd
# --full`) for those. If the repo copy ever drifts far enough to give wrong
# flags, prefer `qmd skill install --global`, which writes a thin bootstrap that
# loads the CLI's instructions at runtime instead of a frozen copy.
